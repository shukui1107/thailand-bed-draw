# 旅行床位抽籤

多人旅行訂好住宿後，用來公平抽「誰睡哪張床」的小網頁。輸入旅伴名單、設定住宿與床位，按一下，名字會像老虎機一樣滾動，最後決定每個人的床。

單一 HTML 檔，不需要安裝、不需要伺服器，雙擊 `index.html` 就能用，也可以放到 GitHub Pages 讓朋友直接開。

## 功能

- **自訂住宿：** 可新增多間住宿（最多 8 間），每間自訂名稱與天數（晚數，最多 14 晚）
- **自訂床位：** 每間住宿可自由組合床位種類與數量，內建單人床、雙人床、三人床，也可以自訂名稱與可睡人數（1 到 10 人）
- **每晚各抽一次：** 住宿天數大於 1 時，每一晚都會重新抽，各自有結果
- **跑馬燈動畫：** 每個位子有垂直滾動的名字條，可以看到前後可能抽到的人
- **結果已定就不跑動畫：** 剩下的人全都睡同一張床時（例如最後一張雙人床剩兩人），直接滑入
- **快速模式：** 勾選後不跑動畫，一次填入全部結果，適合天數很多的行程。預設關閉，每次打開頁面都會回到關閉
- **重設結果：** 清掉所有抽籤結果，名單與住宿設定不變；「還原預設設定」則會把名單和住宿一起還原
- **音效與特效：** 滴答聲、叮聲、結尾小號角（用瀏覽器的 Web Audio 即時產生，沒有音檔）、彩帶與畫面震動。音效可關閉；系統設定「減少動態效果」時不會震動
- **彩色名字標籤：** 每個人有固定顏色，名字很長時自動換行
- **自動儲存：** 名單與住宿設定會存在瀏覽器的 localStorage，下次打開還在；按「還原預設設定」可清除

## 使用方式

1. 用瀏覽器打開 `index.html`
2. 展開「修改名單」，一行一個名字（也可以用逗號、頓號分開）。預設名單是範例，請換成自己的旅伴
3. 在每張住宿卡片展開「編輯住宿與床位」，填入名稱、天數、床位種類與數量
4. 按「全部住宿一起抽」，或在卡片下按「抽這間」只抽單一住宿

床位的總人數需要大於或等於旅伴人數。人數比位子少時，沒抽到人的位子會顯示「空著」；人數比位子多時會提示調整。

## 公平性

結果在動畫開始前就用 `crypto.getRandomValues` 洗牌決定，動畫只是演出，不會影響結果。

## 部署到 GitHub Pages（選用）

1. 把專案推到 GitHub
2. Repository → Settings → Pages
3. Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`
4. 儲存後等一兩分鐘，就能用 `https://<帳號>.github.io/<repo 名稱>/` 打開

## 測試資料（開發用）

網址加上 `?data=worst`（或 `?dev`）會在畫面底部出現資料切換：Demo、Worst case（超長名字、重複名字、emoji、阿拉伯文、14 晚、10 人床）、Empty、One、10 people。這個模式不會讀寫已儲存的設定。
