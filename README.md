# 泰國床位抽籤

旅行前用來抽床位的小網頁。輸入名單，按一下，名字會像老虎機一樣滾動，最後決定每個人睡哪張床。

單一 HTML 檔，不需要安裝、不需要伺服器，雙擊 `index.html` 就能用。

## 功能

- 兩個住宿分開抽，每個住宿都會把全部人抽進去
- 每個位子有垂直跑馬燈動畫，可以看到前後可能抽到的人
- 滴答聲、叮聲、結尾小號角（用瀏覽器的 Web Audio 即時產生，沒有音檔），可隨時關閉
- 停下時有彩帶效果，並且整個畫面會震動一下（系統設定「減少動態效果」時不會震動）
- 剩下的人都睡同一張床時（例如最後一張雙人床剩兩人）不跑抽籤，直接滑入
- 每個人有固定的顏色標籤，名字很長時會自動換行
- 網址加上 `?data=worst`（或 `?dev`）會在畫面底部出現測試資料切換：Demo、Worst case（超長名字、重複名字、emoji、阿拉伯文）、Empty、One、10 people
- 可以「兩晚一起抽」，也可以單獨重抽其中一晚
- 名單可在頁面上直接修改，不用改程式

## 使用方式

1. 用瀏覽器打開 `index.html`
2. 需要的話，展開「修改名單」，一行一個名字（也可以用逗號、頓號分開）
3. 按「兩晚一起抽」，或在各住宿卡片下按「抽這一晚」

## 修改住宿與床位

住宿資料在 `index.html` 裡的 `lodgings` 陣列：

```js
const lodgings = [
  { name:"住宿名稱", tag:"第一個住宿", img:"圖片網址或 data URI",
    beds:[ {t:"單人床",cap:1}, {t:"特大雙人床",cap:2} ] },
];
```

- `t`：床的名稱
- `cap`：這張床睡幾人
- `img`：住宿照片。目前是直接嵌入的 base64，也可以換成相對路徑（例如 `images/foo.jpg`）或網址

人數比床位少時，沒抽到人的位子會顯示「空著」；人數比床位多時會提示錯誤。

預設名單在 `<textarea id="names">` 裡，換成自己的人名即可。

## 公平性

結果在動畫開始前就用 `crypto.getRandomValues` 洗牌決定，動畫只是演出，不會影響結果。

## 部署到 GitHub Pages（選用）

1. 把專案推到 GitHub
2. Repository → Settings → Pages
3. Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`
4. 儲存後等一兩分鐘，就能用 `https://<帳號>.github.io/<repo 名稱>/` 打開

## 關於照片

預設嵌入的住宿照片是從訂房頁面截下來的，版權屬於原房東與飯店。如果要公開 repo，建議換成自己拍的照片，或把 `img` 留空。
